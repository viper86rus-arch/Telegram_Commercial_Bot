## 🌟 Ключевые возможности

1. **📄 Автоматическая генерация смет в PDF (Commercial Proposal):**
   - Формирование официального A4 PDF коммерческого предложения со сметой, таблицей цен, банковскими реквизитами и условиями безотзывной оферты (ст. 435, 438 ГК РФ).
   - Векторный синий штамп простой электронной подписи (ПЭП, 63-ФЗ) с криптографическим хэшем SHA-256 документа.
   - Чистая векторная отрисовка кириллицы на базе системного шрифта Roboto.
   - Моментальная отправка PDF-файла клиенту и администратору сразу после завершения квиза.

2. **💳 Приём платежей и модуль демо-эквайринга (Telegram Payments & Acquiring):**
   - Гибкие тарифные опции: безопасный аванс 30% (с постоплатой после приёмки) или 100% оплата со скидкой 5%.
   - **Гибридный процессинг:** прямая интеграция с нативным **Telegram Payments API** (`sendInvoice`, `pre_checkout_query`, `successful_payment` через ЮKassa/Сбербанк) либо встроенный терминал **демо-эквайринга** с тестовой картой песочницы для мгновенной демонстрации без настройки провайдера.
   - Моментальная фискализация (422-ФЗ «Мой налог»), перевод заказа в статус «В работе» и push-оповещение администратора с прямой ссылкой на диалог с клиентом.

3. **🧠 Умный ИИ-консультант (AI Sales Assistant):**
   - Анализирует вопросы клиентов по парсингу, маркетплейсам (WB, Ozon), ботам и базам данных.
   - Гибридный режим: онлайн-запросы через **Google Gemini API** (при наличии ключа в `.env`) либо мгновенный ответ через встроенную базу знаний IT-Студии.

4. **📁 Интерактивные карточки кейсов в портфолио:**
   - Полноценные карточки реализованных проектов:
     - ⚡ **Async TCP Port Scanner** (asyncio, 10 000 портов за 3 сек).
     - 🕷 **Enterprise Web Scraper** (прокси, антибан, сбор 100k+ товаров).
     - 🤖 **Telegram Commercial Hub** (микро-CRM, квиз, экспорт в Excel/PDF).
   - Прямые ссылки на исходный код в GitHub-репозиториях.

5. **💰 Интерактивный квиз-калькулятор сметы (Inline Stepper):**
   - 3-шаговый расчёт стоимости проекта прямо в диалоге (тип проекта, база данных, онлайн-оплата, админка).
   - Динамический расчёт бюджета и сроков в реальном времени.

6. **🗄 Встроенная микро-CRM на SQLite3 с бизнес-аналитикой:**
   - Автоматический сбор заявок, фиксация статусов оплаты (`paid_advance`, `paid_full`), сумм и номеров транзакций.
   - Расчёт ключевых метрик: общая выручка, конверсия, оплаченные заказы, уникальные клиенты.
   - Мгновенные push-уведомления администратору в Telegram с кнопкой быстрого ответа `[💬 Написать клиенту (@username)]`.

7. **📊 Экспорт базы заявок в Excel (CSV):**
   - Выгрузка всей базы лидов файлом `.csv` прямо в чат Telegram одной кнопкой из админ-панели.
   - Кодировка `UTF-8 с BOM (utf-8-sig)` для идеального открытия в Excel на Windows, Mac и Android без кракозябр.

8. **🛡 Безопасность (.env) и защита прав (RBAC):**
   - Защита административных команд (`/admin`, `/leads`, `/stop`, выгрузка данных) с привязкой к Telegram ID.
   - Вынос токенов и банковских реквизитов в изолированный `.env` файл (защита от утечек на GitHub).

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/viper86rus-arch/Telegram_Commercial_Bot.git
cd Telegram_Commercial_Bot
```

### 2. Настройка конфигурации
Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```
Откройте файл `.env` и впишите ваш токен от `@BotFather`:
```ini
BOT_TOKEN=your_bot_token_here
ADMIN_CHAT_ID=your_telegram_id
DB_PATH=leads.db
# GEMINI_API_KEY=your_key_here (опционально для онлайн-ИИ)
```

### 3. Запуск бота
Сторонние библиотеки (`pip`) **не требуются** — бот работает сразу на любом стандартном Python 3.9+:
```bash
python demo_bot.py
```

## ⚙️ Инженерные решения и особенности

### 1. Векторный генератор PDF-смет со штампом ПЭП (`pdf_generator.py`)
- **Zero Dependencies:** Формирование структуры PDF 1.4 реализовано нативно без `ReportLab`, `WeasyPrint` или Cairo.
- **Векторный штамп цифровой подписи:** Автоматическая генерация синего штампа простой электронной подписи (ПЭП, 63-ФЗ) с уникальным криптографическим хэшем SHA-256, временной меткой по МСК и ИНН исполнителя.
- **Полные банковские реквизиты:** Автоматическое включение платёжных данных (БИК, к/с, р/с, СБП) и условий безотзывной оферты (ст. 435, 438 ГК РФ) для беспрепятственной оплаты через бухгалтерию заказчика.
- **Поддержка кириллицы:** Использование системного шрифта TrueType (`Roboto-Regular.ttf`) через спецификацию `CIDFontType2` и `Identity-H`.
- **Пропорциональный кернинг (`/W`):** Автоматический парсинг горизонтальных метрик (`hmtx`) и расчёт массива ширин глифов, гарантирующий ровные колонки и отсутствие наложения текста.
- **Санитизация глифов (`clean_text_for_pdf`):** Автоматическая фильтрация цветных эмодзи для предотвращения артефактов и технических квадратиков (`▯`) в стандартных PDF-ридерах.

### 2. Модуль платежей и интерактивного эквайринга (`demo_bot.py`)
- **Гибридный процессинг:** Автоматическое определение режима работы:
  - *Боевой / Тестовый через Telegram:* при наличии `PAYMENT_PROVIDER_TOKEN` бот выставляет нативные инвойсы через Telegram Bot API (`sendInvoice`) с поддержкой провайдеров ЮKassa, Сбербанк и др.
  - *Встроенная песочница (Zero-Config):* при отсутствии токена активируется интерактивный терминал с демонстрационной картой (`1111 1111 1111 1026`), позволяющий заказчику или работодателю протестировать оплату в один клик.
- **Тарифное разделение:** Поддержка предоплаты 30% для снижения порога входа клиента либо 100% оплаты со скидкой 5%.
- **Автоматическая фискализация:** Генерация уникального идентификатора чека/транзакции (`#TX-...`) со ссылкой на учёт в «Мой налог» (422-ФЗ).

### 3. Защита от дублирования процессов (Single-Instance PID Lock)
- Встроенный механизм `enforce_single_instance()` на базе файла блокировки `bot.pid`.
- Автоматически находит и завершает устаревшие фоновые процессы при перезапуске, полностью исключая сетевые коллизии Telegram API (`409 Conflict: terminated by other getUpdates request`).

### 4. Микро-CRM и экспорт базы в Excel (UTF-8 BOM) (`database.py`)
- Транзакционное хранилище SQLite3 с автоматической миграцией схемы при обновлениях.
- Фиксация статусов заказов (`new`, `paid_advance`, `paid_full`), сумм оплат и номеров транзакций.
- Расчёт аналитики: общая выручка, число оплаченных заказов, конверсия и уникальные клиенты.
- Выгрузка отчёта `.csv` с маркером последовательности байтов `\xef\xbb\xbf` (`utf-8-sig`). Это гарантирует корректное открытие отчёта в Microsoft Excel на Windows, macOS и мобильных устройствах без повреждения кириллицы.

### 5. Гибридный ИИ-консультант (`ai_assistant.py`)
- Прямой вызов Google Gemini REST API через стандартный `urllib.request`.
- Интеллектуальный Fallback: при отсутствии API-ключа или сбоях сети бот автоматически переключается на встроенную локальную базу знаний, обеспечивая клиентам ответы о сроках, стеке и гарантиях без задержек.

## 🔒 Административная панель

Бот содержит встроенную панель управления для владельца с авторизацией по `ADMIN_CHAT_ID`:
* `/admin` — сводка аналитики в реальном времени: число лидов, уникальные заказчики, количество оплаченных заказов и суммарная выручка (₽).
* `/leads` — оперативный просмотр 5 последних заявок с бейджами оплат (`💳 15 000 ₽ (#TX-...)` / `⏳ Ожидает оплаты`).
* Кнопка **«📥 Выгрузить базу в Excel (CSV)»** — отправка актуального отчёта файлом прямо в чат Telegram со всеми платёжными деталями.
* `/stop` — безопасное завершение сессии с подтверждением смещения `offset` на серверах Telegram.

## 📋 Техническая спецификация

| Параметр | Значение |

| **Язык** | Python 3.9+ |
| **Зависимости** | 0 сторонних пакетов (100% Python Standard Library) |

| **Среда выполнения** | Linux, macOS, Windows, Android (Termux / Antigravity) |
