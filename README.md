# 🤖 Telegram Commercial Hub & Lead-Gen Bot (v2.0)

> **Высокопроизводительный коммерческий Telegram-бот под ключ для бизнеса, IT-студий и фрилансеров.**  
> Разработан на **чистом Python 3** с использованием встроенной стандартной библиотеки (Zero external dependencies).

---

## 🌟 Ключевые возможности

1. **💰 Интерактивный квиз-калькулятор сметы (Inline Stepper):**
   - Пошаговый расчёт стоимости проекта прямо в диалоге Telegram (выбор типа разработки, БД, платёжных шлюзов, админ-панели).
   - Динамический расчёт сроков и бюджета в реальном времени.
   - Фиксация заказа в 1 клик с передачей полной спецификации разработчику.

2. **🗄 Встроенная микро-CRM на SQLite3:**
   - Автоматический сбор и каталогизация входящих заявок и лидов.
   - Защита данных клиентов, персистентность состояния при перезагрузках сервера.

3. **🔔 Мгновенные push-уведомления администратору:**
   - Карточка каждого нового лида сразу прилетает в личные сообщения владельцу.
   - Кнопка быстрого ответа `[💬 Написать клиенту (@username)]` для закрытия сделки без ручного поиска контактов.

4. **📊 Экспорт базы заявок в Excel (CSV):**
   - Выгрузка всей базы лидов файлом `.csv` прямо в чат Telegram одной кнопкой.
   - Кодировка `UTF-8 с BOM (utf-8-sig)` для идеального открытия в Excel на Windows, Mac и Android без кракозябр.

5. **🛡 Ролевая модель безопасности (RBAC) & Безопасность (.env):**
   - Защита административных команд (`/admin`, `/leads`, `/stop`, выгрузка данных) с привязкой к Telegram ID.
   - Вынос токенов и секретов в изолированный `.env` файл (защита от утечек на GitHub).

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/viper86rus-arch/telegram-commercial-bot.git
cd telegram-commercial-bot
```

### 2. Настройка конфигурации
Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```
Откройте файл `.env` и впишите ваш токен от `@BotFather`:
```ini
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_CHAT_ID=707755583
DB_PATH=leads.db
```

### 3. Запуск бота
Сторонние библиотеки (`pip`) **не требуются** — бот работает сразу на любом стандартном Python 3.9+:
```bash
python demo_bot.py
```
